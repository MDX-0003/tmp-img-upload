# tmp-img-upload

Public image host for PICOSplat render-test contact sheets.

- One folder per run: `runs/<run_id>/contact_sheet.jpg` + `manifest.json`.
- Only contact sheets / summarized images go here. Do not upload raw engine logs, CSVs,
  full screenshot sequences, or project source.
- Raw URL form: `https://raw.githubusercontent.com/MDX-0003/tmp-img-upload/<commit>/runs/<run_id>/contact_sheet.jpg`.
- The repo is public; anyone with the URL can view the images.
